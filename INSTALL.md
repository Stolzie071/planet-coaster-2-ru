# Установка русификатора

Для **Planet Coaster 2 1.12.2**, Steam / Windows, сборка **26255360**. Версия русификатора – **1.06**.

## Установить

1. **Закройте Planet Coaster 2.**
2. В библиотеке Steam нажмите правой кнопкой по игре → **Свойства → Общие → Язык → English**. Если Steam начнёт загрузку, дождитесь окончания.
3. В **Свойства → Установленные файлы → Обзор** откройте папку игры. В ней уже должны быть папки **Win64** и **Parks**.
4. Откройте [последний релиз](https://github.com/Stolzie071/planet-coaster-2-ru/releases/latest). В списке **Assets** скачайте **Planet_Coaster_2_RU_1.06_Game_1.12.2.zip**. Файлы **Source code (zip)** и **Source code (tar.gz)** не являются русификатором.
5. Распакуйте скачанный ZIP в отдельную папку. Скопируйте из него **обе папки, Win64 и Parks**, в папку игры.
6. Подтвердите объединение папок и замену одноимённых файлов.
7. Запустите игру. Английский текст будет заменён русским. В Steam оставьте **English**.

Должно получиться:

```text
Planet Coaster 2
├── Win64
│   └── ovldata
│       └── ...
└── Parks
    ├── Career
    │   └── ...
    └── Challenge
        └── ...
```

Папок `Win64\Win64` и `Parks\Parks` быть не должно. Отдельные программы, установщики и загрузчики модов для установки не требуются.

**Зачем нужна Parks:** в семи исходных картах переведены названия ингредиентов внутри готовых мыслей посетителей. Они были сохранены по-английски даже при выборе других языков. Исправление видно при новом запуске соответствующей миссии; уже созданное сохранение содержит собственные данные и автоматически не обновится. Для обычных правок интерфейса начинать заново не требуется.

## Обновить

Проверьте совместимую версию игры в описании нового релиза. Закройте игру и повторите установку новой сборки с заменой файлов.

Steam может заменить перевод при обновлении или проверке целостности. В этом случае установите подходящую сборку повторно. Если совместимость с новым патчем ещё не подтверждена, старый архив поверх него пока не устанавливайте.

## Удалить

1. Закройте игру.
2. В свойствах Steam оставьте язык **English**.
3. Выберите **Свойства → Установленные файлы → Проверить целостность файлов игры**.
4. Дождитесь окончания проверки и загрузки оригинальных файлов.

Steam восстановит английскую локализацию и исходные карты. Удалять игру целиком не нужно. Сохранения русификатор не изменяет.

## Если текст остался английским

- Проверьте, что выбран **English**.
- Проверьте, что файлы скопированы именно в папку текущей установки игры, а не в другую копию.
- Проверьте путь `Win64\ovldata` и отсутствие вложенной папки `Win64\Win64`.
- Если в готовых мыслях карьеры остались английские ингредиенты, проверьте копирование **Parks**. В старом сохранении прежние названия могут остаться даже после правильной установки.
- Полностью перезапустите игру после копирования.
- Если после копирования Steam снова загружал игровые файлы, дождитесь окончания и установите совместимую сборку заново.

## Если игра не запускается

Восстановите оригинальные файлы проверкой целостности и проверьте запуск без перевода. Сообщите о результате в [Issues](https://github.com/Stolzie071/planet-coaster-2-ru/issues), указав версии игры и русификатора и описание проблемы.

## Что входит в архив

- 42 файла текстовой локализации UK/US в папке **Win64**.
- 7 исправленных исходных карт в папке **Parks**: 4 карты карьеры и 3 карты испытаний.
- **УСТАНОВКА.txt** с инструкцией.
- **manifest.json** с версией и контрольными суммами файлов.

Включены тексты основной игры и дополнений, поставляемые с проверенной версией. Озвучка остаётся оригинальной. Перевод не открывает платные дополнения.

Рядом с ZIP в релизе лежит файл **.sha256** для необязательной проверки целостности скачивания. Для обычной установки он не требуется.
