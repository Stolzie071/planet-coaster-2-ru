# Установка русификатора

Проверено с **Planet Coaster 2 1.12.2**, Steam / Windows, сборка **26255360**. Версия русификатора — **1.02**.

## Установить

1. **Закрой Planet Coaster 2.**
2. В библиотеке Steam нажми правой кнопкой по игре → **Свойства → Общие → Язык → English**. Если Steam начнёт загрузку, дождись окончания.
3. В **Свойства → Установленные файлы → Обзор** открой папку игры. В ней уже должна быть папка **Win64**.
4. Открой [последний релиз](https://github.com/Stolzie071/planet-coaster-2-ru/releases/latest). В списке **Assets** скачай **Planet_Coaster_2_RU_1.02_Game_1.12.2.zip**. Файлы **Source code (zip)** и **Source code (tar.gz)** не являются русификатором.
5. Распакуй скачанный ZIP в отдельную папку. Скопируй из него папку **Win64** в папку игры.
6. Подтверди объединение папок и замену одноимённых файлов.
7. Запусти игру. Английский текст будет заменён русским. В Steam оставь **English**.

Должно получиться:

```text
Planet Coaster 2
└── Win64
    └── ovldata
        └── ...
```

Папки `Win64\Win64` быть не должно. Отдельные программы, установщики и загрузчики модов для установки не требуются.

## Обновить

Проверь совместимую версию игры в описании нового релиза. Закрой игру и повтори установку новой сборки с заменой файлов.

Steam может заменить перевод при обновлении или проверке целостности. В этом случае установи подходящую сборку повторно. Если совместимость с новым патчем ещё не подтверждена, старый архив поверх него пока не устанавливай.

## Удалить

1. Закрой игру.
2. В свойствах Steam оставь язык **English**.
3. Выбери **Свойства → Установленные файлы → Проверить целостность файлов игры**.
4. Дождись окончания проверки и загрузки оригинальных файлов.

Steam восстановит английскую локализацию. Удалять игру целиком не нужно. Сохранения русификатор не изменяет.

## Если текст остался английским

- Проверь, что выбран **English**.
- Проверь, что файлы скопированы именно в папку текущей установки игры, а не в другую копию.
- Проверь путь `Win64\ovldata` и отсутствие вложенной папки `Win64\Win64`.
- Полностью перезапусти игру после копирования.
- Если после копирования Steam снова загружал игровые файлы, дождись окончания и установи совместимую сборку заново.

## Если игра не запускается

Восстанови оригинальные файлы проверкой целостности и проверь запуск без перевода. Сообщи о результате в [Issues](https://github.com/Stolzie071/planet-coaster-2-ru/issues), указав версии игры и русификатора и описание проблемы.

## Что входит в архив

- 42 файла текстовой локализации UK/US в папке **Win64**.
- **УСТАНОВКА.txt** с инструкцией.
- **manifest.json** с версией и контрольными суммами файлов.

Включены тексты основной игры и дополнений, поставляемые с проверенной версией. Озвучка остаётся оригинальной. Перевод не открывает платные дополнения.

Рядом с ZIP в релизе лежит файл **.sha256** для необязательной проверки целостности скачивания. Для обычной установки он не требуется.
